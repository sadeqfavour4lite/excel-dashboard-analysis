# Excel Dashboard Analysis

## Project Overview
This project is an interactive Excel dashboard developed for business intelligence, KPI tracking, and data-driven decision-making. The dashboard provides insights into business performance using visual analytics and Excel dashboarding techniques.

## Features
- Interactive dashboard
- KPI tracking
- Data visualization
- Pivot tables and charts
- Slicers and filters
- Business insights reporting

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Conditional Formatting
- Data Cleaning
- Dashboard Design
